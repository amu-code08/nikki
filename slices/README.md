# slices

`$tag-dailies` が、複数の話題が混ざった daily を話題ごとに切り出してここへ置く。

- ファイル名は `YYYY-MM-DD--<domain>.md`(例:`2026-08-10--finance.md`)。domain は話題タグの `/` より前。
- **本文は daily の行の逐語コピー。** 要約でも言い換えでもない。
- **正本は常に daily 側。** ここは話題単位で読み返すための派生層にすぎない。
- 話題の domain が2つ以上ある日だけ切り出す。1つしかない日は daily 自体がその話題のノートなので作らない。
- 分析対象外。タグ分布・todo 収集・`$resurface-ideas` はすべて daily を見る。両方読むと同じ記述を二重に数える。
- チェックボックス行は持たない。daily 側でチェックすると状態が食い違うため。
- 書き換え・整理・削除は人間の仕事。エージェントは新規作成しかせず、既存の slice を上書きしない。
